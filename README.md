# Frame Notes

A small phone web app for reviewing a video frame by frame: pause, circle with a pen, drop a text note where you drag, select to move or delete a mark, pinch to zoom. Notes stay on the phone (IndexedDB). "Send to Claude" exports one JSON file with every marked frame as a picture plus the notes, saved through the share sheet.

No server, no tracking, no uploads. The video never leaves the device.

Open on iPhone in Safari, then Share › Add to Home Screen.
